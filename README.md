# AI in Finance: Finance for Engineers, Scientists, and Data Scientists

Wulin Suo, Smith School of Business, Queen's University

I have written this book for readers who are already comfortable with quantitative reasoning and, ideally,
with basic Python, but who have limited exposure to finance and economics: graduate students and advanced
undergraduates in engineering, the physical sciences, statistics, and computer science; practicing
data scientists and machine learning engineers moving into a financial role; and anyone building a career
on the specific combination of skills this book covers. No prior finance coursework is assumed. Chapter
3 introduces financial markets and institutions from first principles, and every subsequent chapter builds
forward from there, so a reader with no finance background at all should be able to start at Chapter 1 and
never feel lost.

The book is a draft that I am still actively revising. Every chapter is sized for a 90-minute class and
contains at least one fully worked numerical example a reader can check by hand, a discussion of the
practical challenges of its topic, exercises, and pointers to further reading. Every number in the text is
reproduced by the chapter's companion notebook.

**Read the book:** [ai_in_finance.pdf](ai_in_finance.pdf) (the whole book), or the individual chapter PDFs in
[chapters/](chapters/).

## Running the notebooks

The notebooks need Python 3.14 and the package versions pinned in [requirements.txt](requirements.txt),
which are the versions that produced the outputs shown in the notebooks and quoted in the text:

```bash
python -m pip install -r requirements.txt     # or: conda env create -f environment.yml
jupyter lab notebooks/
```

To run a notebook without installing anything, open it in Google Colab from the badge in the table above
(its first cell installs the pinned versions when it detects Colab), or launch the whole folder on
Binder: [![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/wulinsuo/AI-in-Finance/main?labpath=notebooks)
(the environment is defined in [binder/](binder/)). On Colab the Chapter 7 notebook reads its Treasury file
from this repository, and the notebooks that export the book's figures skip the export.

All 21 notebooks run in about five minutes in total. Chapter 5 downloads VIX history with `yfinance` and
Chapter 21 downloads its dataset from the UCI Machine Learning Repository on first run; Chapter 7 reads a
Treasury yield-curve file included in [notebooks/ch7_data/](notebooks/ch7_data/). The other notebooks need
no network access.

The Chapter 16, 17 and 19 notebooks end with an optional "at scale" section that trains or runs real deep-learning
models (PyTorch, Hugging Face transformers, stable-baselines3) instead of hand-picked weights. These need the extra
packages in [requirements-dl.txt](requirements-dl.txt) (`python -m pip install -r requirements-dl.txt`, CPU-only
PyTorch), and Chapter 16's downloads about 420 MB of pretrained model weights on first run. Without these packages
the sections skip themselves; their numbers are not reproducible digit for digit, so the check below skips them too.

To check that every notebook still reproduces its committed output (useful after changing a package
version or a cell):

```bash
python tools/check_notebooks.py               # all notebooks
python tools/check_notebooks.py --no-network  # skip Chapters 5 and 21
```

The same check runs automatically on GitHub on every change to the notebooks.

## Building the book

The book is written in LaTeX. With a TeX distribution installed (TeX Live or MiKTeX), build the whole book
from the repository root:

```bash
pdflatex ai_in_finance.tex
biber ai_in_finance
makeindex ai_in_finance.idx
pdflatex ai_in_finance.tex
pdflatex ai_in_finance.tex
```

Citations come from [references.bib](references.bib) through biblatex, so `biber` (included in TeX Live and
MiKTeX) must run between the LaTeX passes. A single chapter compiles on its own from inside `chapters/`:
`pdflatex chapter9.tex`, `biber chapter9`, then `pdflatex chapter9.tex` twice.
